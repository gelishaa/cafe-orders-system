# User Stories

### 1. Як офіціант, я хочу швидко створити нове замовлення, вказавши столик і обрані страви, щоб передати його на кухню без затримок.

**Acceptance criteria:**
- Можна обрати столик і додати одну або декілька страв з меню
- Замовлення зберігається та одразу стає видимим для кухні
- Система показує підтвердження про успішне створення замовлення

### 2. Як офіціант, я хочу бачити поточний статус замовлення (готується / готове), щоб вчасно повідомити клієнта або забрати страву з кухні.

**Acceptance criteria:**
- Статус замовлення відображається одним із значень: нове / готується / готове / видано
- Зміна статусу на кухні одразу відображається в інтерфейсі офіціанта
- Якщо замовлення не знайдено - система показує відповідне повідомлення

### 3. Як адміністратор, я хочу переглядати список замовлень за обраний день, щоб проаналізувати завантаженість закладу та обсяг продажів.

**Acceptance criteria:**
- Можна обрати конкретну дату для перегляду замовлень
- Список показує кількість замовлень і загальну суму за обраний день
- Якщо за обрану дату замовлень немає - система показує відповідне повідомлення
