# Вимоги до системи
### Функціональні вимоги
1. Система повинна забезпечувати реєстрацію нового замовлення: вибір страв з меню, вказання кількості та номера столика.
2. Система повинна дозволяти редагувати склад замовлення (додавання/видалення позицій) до моменту його оплати.
3. Система повинна дозволяти скасовувати (видаляти) замовлення.
4. Система повинна відображати та дозволяти оновлювати статус замовлення: нове → готується → готове → видано → оплачено.
5. Система повинна забезпечувати пошук і фільтрацію замовлень за датою, статусом або номером столика.

### Нефункціональні вимоги
1. Продуктивність. Основні операції мають виконуватися швидко.
2. Надійність. Дані про замовлення не повинні втрачатися при перезапуску системи.
3. Зручність використання. Інтерфейс має бути інтуїтивно зрозумілим для персоналу.
4. Масштабованість. Архітектура системи повинна допускати додавання нових функцій без суттєвої переробки існуючого коду.
5. Безпека. Доступ до адміністративних функцій (редагування меню тощо) має бути захищений автентифікацією користувача.
