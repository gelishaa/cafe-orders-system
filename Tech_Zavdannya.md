# Технічне завдання
## Мета і завдання продукту
Мета: створити веб-застосунок, який автоматизує прийом, обробку та облік замовлень у невеликому кафе і замінює ручний облік. 
<br> Завдання: 
1. реалізувати реєстрацію замовлень з вибором страв із меню;
2. забезпечити відстеження статусу виконання кожного замовлення;
3. зберігати дані замовлень у  базі даних;
4. забезпечити  пошук замовлень та їх перегляд;
5. розділити програму на шари: представлення, бізнес-логіка, доступ до даних.
6. реалізувати ранжування страв за популярністю як додатковий інтелектуальний компонент.
<br> Користувачі: офіціант/касир та адміністратор кафе.

## Функціональні вимоги
1. Система повинна забезпечувати реєстрацію нового замовлення: вибір страв з меню, вказання кількості та номера столика.
2. Система повинна дозволяти редагувати склад замовлення (додавання/видалення позицій) до моменту його оплати.
3. Система повинна дозволяти скасовувати (видаляти) замовлення.
4. Система повинна відображати та дозволяти оновлювати статус замовлення: нове → готується → готове → видано → оплачено.
5. Система повинна забезпечувати пошук і фільтрацію замовлень за датою, статусом або номером столика.
6. Система повинна формувати рейтинг найпопулярніших страв за обраний період: страви ранжуються за кількістю замовлених порцій, а за однакової кількості за виручкою.

## Нефункціональні вимоги
1. Продуктивність. Основні операції мають виконуватися швидко.
2. Надійність. Дані про замовлення не повинні втрачатися при перезапуску системи.
3. Зручність використання. Інтерфейс має бути інтуїтивно зрозумілим для персоналу.
4. Масштабованість. Архітектура системи повинна допускати додавання нових функцій без суттєвої переробки існуючого коду.
5. Безпека. Доступ до адміністративних функцій (редагування меню тощо) має бути захищений автентифікацією користувача.

## Обмеження
Технології: мова PHP, база даних MySQL (адміністрування через phpMyAdmin), система контролю версій Git (GitHub).
<br>Тип продукту: веб-застосунок для одного закладу з невеликим навантаженням.

## Очікувані результати
1. Працюючий веб-застосунок (MVP), що реалізує вимоги.
2. База даних MySQL з  структурою.
3. Git-репозиторій.
4. Діаграми: Use Case, Class, Sequence, Activity.
