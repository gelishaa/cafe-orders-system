# cafe-orders-system

## Опис проєкту
Система обліку замовлень у невеликому кафе.
Система призначена для автоматизації прийому та обробки замовлень у кафе: 
реєстрація замовлень, керування меню, відстеження статусу виконання замовлення.
**Користувачі системи:** офіціант/касир, адміністратор (власник) кафе.

## Ролі
1. **Аналітик** - визначення вимог, опис предметної області;
2. **Архітектор** - проєктування структури системи;
3. **Розробник** - реалізація функціоналу;
4. **Тестувальник (QA)** - написання та виконання тестів;
5. **Автор документації** - ведення документації.

## Вимоги
### Функціональні вимоги
1. Реєстрація нового замовлення (страви, кількість, номер столика)
2. Редагування складу замовлення до моменту оплати
3. Скасування (видалення) замовлення
4. Відображення та оновлення статусу замовлення (нове → готується → готове → видано → оплачено)
5. Пошук і фільтрація замовлень за датою, статусом або столиком

### Нефункціональні вимоги
1. Продуктивність: основні операції виконуються швидко
2. Надійність: дані не втрачаються при перезапуску системи
3. Зручність використання: інтуїтивний інтерфейс
4. Масштабованість: можливість розширення функціоналу без переробки системи
5. Безпека: автентифікація для доступу до адміністративних функцій
