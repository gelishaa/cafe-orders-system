# cafe-orders-system

## Опис проєкту
Система обліку замовлень у невеликому кафе.
Система призначена для автоматизації прийому та обробки замовлень у кафе: 
реєстрація замовлень, керування меню, відстеження статусу виконання замовлення.
**Користувачі системи:** офіціант/касир, адміністратор (власник) кафе.

## Ролі
**Аналітик** - визначення вимог, опис предметної області
**Архітектор** - проєктування структури системи
**Розробник** - реалізація функціоналу
**Тестувальник (QA)** - написання та виконання тестів
**Автор документації** - ведення документації
